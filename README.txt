PÁGINA WEB DE PODCAST — COBERTURA LIMITADA DE MEDICAMENTOS ESENCIALES EN EL PERÚ

ARCHIVOS
- index.html: página web completa y adaptable a móvil.
- podcast.mp3: audio incluido.
- README.txt: instrucciones.

ABRIR EN VISUAL STUDIO CODE
1. Extrae el ZIP en una carpeta.
2. Abre la carpeta en Visual Studio Code.
3. Instala la extensión Live Server.
4. Haz clic derecho en index.html > Open with Live Server.
5. Pulsa reproducir en el reproductor de audio.

LIKES Y COMENTARIOS
- El contador comienza en 1.000 likes de muestra. Al pulsar el corazón, sube a 1.001; al volver a pulsarlo, se quita tu like.
- Incluye 50 comentarios ficticios de ejemplo: positivos, críticas constructivas, propuestas de mejora y reflexiones.
- Los comentarios nuevos se muestran en la página y se guardan en el navegador local.
- IMPORTANTE: sin backend, los likes y comentarios no se comparten entre usuarios/dispositivos. Para que sean globales, conecta una base de datos (p. ej., Supabase o Firebase) y configura seguridad/moderación.
- Las cifras iniciales son de muestra y no representan actividad real verificada.

PUBLICAR EN GITHUB PAGES
1. Crea un repositorio en GitHub y sube index.html, podcast.mp3 y README.txt a la raíz.
2. En el repositorio entra a Settings > Pages.
3. En Build and deployment, selecciona Deploy from a branch.
4. Elige la rama main y la carpeta /(root), y guarda.
5. Espera la publicación y copia la URL mostrada en Settings > Pages.

La URL pública funciona mientras el repositorio y GitHub Pages sigan publicados. El audio está incluido en el ZIP y no depende de este chat.
